# MyPortfolio — Responsive Personal Portfolio

A beginner-friendly, original single-page student portfolio. All illustrations are original local SVG files. No framework or server is required.

## Open it

Open `index.html` in a modern browser, or upload the **contents** of this directory (not the ZIP) to the root of a GitHub repository and enable GitHub Pages at Settings → Pages → Deploy from a branch → main → /(root).

## Four interactive extras

1. **Light/dark theme button** — changes theme and remembers it in localStorage; honors system preference until manually overridden.
2. **Project filter** — displays all, HTML/CSS, or JavaScript cards; announces the count to assistive technology.
3. **Accessible image preview** — native dialog opens using mouse, Enter or Space; Escape closes it; focus returns to the gallery button.
4. **Contact form validation** — checks name, email, and message and provides accessible feedback. **Demo only: messages are not sent or stored on a server.**

Other features: semantic landmarks and headings, skip-to-content link, alt text, visible focus indicators, responsive CSS grids and flex navigation, reduced-motion support, current-year footer.

## Evidence to collect for Coursera

- **Responsive**: screenshots with DevTools at mobile (390px), tablet (800px), desktop (1200px).
- **W3C validation**: publish first, then open https://validator.w3.org/ and validate your public site URL; capture results.
- **WAVE**: paste your published page URL into https://wave.webaim.org/; capture the report, fix any errors reported.
- **Four extras**: test and screenshot the theme switch, filters, image dialog, and form validation.

Site link format: `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/`
